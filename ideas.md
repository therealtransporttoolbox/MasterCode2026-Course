**Approach 1: Industrial Authority (Bauhaus-Inspired)**

Design Movement: Bauhaus Functionalism meets Australian Government Authority

Core Principles:
1. Structural clarity — every element earns its place through function
2. Bold typographic hierarchy — headlines command attention, body text supports
3. Systematic colour coding — each module has a distinct accent within a unified palette
4. Grid-based asymmetry — left-anchored sidebar navigation with generous content canvas

Color Philosophy: Deep navy (#0B1F3A) as the authority base, with NHVR orange-amber (#E8720C) as the primary action colour. Steel grey (#4A5568) for secondary text. White (#FFFFFF) content areas. The palette evokes road infrastructure, safety signage, and government trust.

Layout Paradigm: Persistent left sidebar showing course progress tree. Main content area with wide reading column. Module header banners using diagonal clip-path cuts.

Signature Elements:
1. Orange progress bar running along the top of each lesson
2. Numbered module badges in bold sans-serif
3. Case study cards with a left border accent stripe

Interaction Philosophy: Every interaction confirms progress — checkmarks animate in, progress bars fill, knowledge check answers reveal explanations with colour feedback.

Animation: Subtle slide-in for lesson content, fade transitions between modules, progress ring animation on module completion.

Typography System: Barlow Condensed (700) for module titles, Source Serif 4 (400/600) for body content, JetBrains Mono for code/legal references.

**Approach 2: Clean Professional (Selected)**

Design Movement: Modern Government Digital Service — clean, accessible, trustworthy

Core Principles:
1. Legibility first — optimised for reading dense regulatory content
2. Progressive disclosure — complex content revealed step by step
3. Visual anchoring — consistent left-rail navigation keeps users oriented
4. Warm neutrals — avoids clinical coldness while maintaining professionalism

Color Philosophy: Off-white (#F8F9FA) background for reduced eye strain during long reading sessions. Deep slate (#1E293B) for primary text. NHVR brand blue (#003087) for navigation and CTAs. Amber (#F59E0B) for warnings and knowledge checks. Green (#10B981) for completion states.

Layout Paradigm: Two-column layout — fixed sidebar (280px) with collapsible module tree on left, scrollable lesson content on right. Mobile collapses to drawer navigation.

Signature Elements:
1. Module completion rings in the sidebar
2. Callout boxes with left-border accents for key definitions and case studies
3. Knowledge check cards with animated reveal of correct/incorrect answers

Interaction Philosophy: Linear progression with optional branching — learners must complete lessons in order but can revisit any completed content. Knowledge checks gate progression.

Animation: Smooth sidebar transitions, content fade-in on lesson load, celebratory micro-animation on module completion.

Typography System: DM Sans (400/600/700) for UI elements, Lora (400/600) for lesson body text to aid reading comprehension of dense legal content.

**Approach 3: Bold Transport (Road-Inspired)**

Design Movement: Road Safety Campaign meets Digital Learning Platform

Core Principles:
1. High contrast — inspired by road signage for maximum clarity
2. Section-based storytelling — each module feels like a chapter in a journey
3. Kinetic energy — subtle motion suggests movement and progress
4. Chunked content — bite-sized lessons with clear start/end points

Color Philosophy: Charcoal (#1C1C1E) primary background with high-contrast white text. Yellow (#FFD60A) as the primary accent — evoking road markings and caution signs. Red (#FF3B30) for warnings and critical compliance points. The palette is bold, memorable, and safety-focused.

Layout Paradigm: Top navigation bar with module tabs. Full-width lesson cards stacked vertically. Progress tracked via a horizontal stepper at the top of each module.

Signature Elements:
1. Road-marking style dividers between sections
2. Warning sign iconography for compliance-critical content
3. Dashboard-style module overview with completion statistics

Interaction Philosophy: Gamified progression — points for completing lessons, badges for module completion, leaderboard for team training contexts.

Animation: Slide-in transitions mimicking page turns, speed-gauge animation for progress, confetti on course completion.

Typography System: Bebas Neue for bold section headers, Nunito Sans (400/600) for body text, monospace for legal references.

## Selected Approach: Approach 2 — Clean Professional

This approach best serves the audience (transport industry professionals, executives, CoR parties) who need to absorb dense regulatory content efficiently. The clean layout prioritises readability, the progressive disclosure structure mirrors the MCG course builder's module/lesson/knowledge-check flow, and the NHVR blue palette aligns with the regulator's brand identity.
